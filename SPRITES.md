# Подключение собственных спрайтов

В приложении уже подключены 151 анимированный покемон первого поколения из PokéAPI/sprites. Ниже описан формат, чтобы добавить или заменить персонажей. Анимации задаются отдельно от логики сцены.

## Папки

- Исходный проект: `public/sprites/` (после изменений выполнить `npm run build`).
- Распакованный Windows-релиз: `dist/public/sprites/` (сборка не нужна).

Положи в папку PNG или WebP с прозрачным фоном. Изображение — равномерная сетка кадров. Для статичного персонажа подходит картинка с одним кадром.

## Пример manifest.json

```json
{
  "skins": [
    {
      "id": "fox",
      "name": "Лис",
      "image": "/sprites/fox.png",
      "frameWidth": 32,
      "frameHeight": 32,
      "columns": 4,
      "rows": 2,
      "fps": 8,
      "animations": {
        "idle": [0, 1],
        "walk": [2, 3, 4, 5],
        "jump": [6],
        "dance": [6, 7]
      }
    }
  ]
}
```

Нумерация кадров начинается с **0**, слева направо, затем следующая строка. В примере изображение имеет размер **128×64**. Если анимация не указана, используется `idle`; если `idle` нет — кадр 0. `columns`, `rows`, размеры кадра и `fps` обязательны.

По умолчанию персонажи в исходном изображении смотрят **вправо**. Для персонажей, смотрящих влево, добавь `"facing": "left"` (так настроены покемоны). При смене направления сцена зеркалит кадр. Все кадры имеют одинаковый размер и положение ступней у нижнего края, чтобы персонаж не прыгал между кадрами. Отображаемый размер задаётся в панели; исходный размер PNG может быть любым в допустимых пределах.

Для одного статичного PNG: `frameWidth`/`frameHeight` равны размерам картинки, `columns: 1`, `rows: 1`, `fps: 1`, `animations: { "idle": [0] }`. Сцена всё равно добавит движение и прыжок.

Пустой `skins: []` включает шесть временных персонажей. Непустой массив заменяет их. `!skin 1` выбирает номер Покедекса (`dexNumber`), если он есть, иначе первый элемент; `!skin fox` выбирает ID. ID должны быть уникальны и состоять из латинских строчных букв, цифр, `_` или `-`, до 40 символов. Изображения только локальные в `/sprites/`, без `..`. До 2048 вариантов и до 8192×8192 на изображение; лучше использовать небольшие атласы.

Необязательные поля:

- `preview`: путь к отдельному PNG/WebP-портрету для каталога и списка участников (например, `/sprites/pokemon/thumbs/25.png`). Сам атлас не подходит для портрета.
- `dexNumber`: уникальный номер 1–1025 для выбора покемона через `!skin 25`.
- `frameDurations`: длительность каждого кадра атласа в миллисекундах. Например, `[100, 250, 100]`. Индексы соответствуют кадрам атласа, а не порядку в отдельной анимации. Если поле есть, длительности должны быть заданы для всех используемых кадров. Если его нет, применяется `fps`. Пауза останавливает и покадровую анимацию.

Перезапусти сервер после изменения списка. При ошибке манифеста сервер пишет предупреждение и использует временных персонажей. Если манифест корректен, но изображение отсутствует или меньше объявленной сетки, персонаж заменяется временным; предпросмотр показывает ошибку. Сам оверлей OBS не выводит сообщение об ошибке файла в эфир.

Произвольные атласы с кадрами разного размера пока не поддерживаются. Импортер `scripts/import-pokemon.py` преобразует GIF PokéAPI в равномерную сетку, сохраняет исходный тайминг, объединяет последовательные одинаковые кадры и обрезает прозрачные поля одинаково для всех кадров. Источники и SHA-256 исходных файлов — `pokemon/SOURCE.json`, лицензия — `pokemon/LICENSE-PokeAPI.txt`. Во время стрима запросов к GitHub или PokéAPI нет.
