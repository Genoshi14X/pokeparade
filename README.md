# PokéParade

Локальная сцена для OBS на Windows: до 40 персонажей зрителей Twitch и 493 анимированных покемона поколений I–IV и их shiny-версии из PokéAPI/sprites. Прозрачный оверлей, прогулка вдоль нижнего края, очередь участников и панель управления на русском. Без платного сервера.

## Запуск на игровом ПК с Windows

1. Установи **Node.js 22 или новее** с https://nodejs.org и распакуй `PokeParade-Windows.zip` в отдельную папку. Не запускай файлы внутри ZIP.
2. Дважды нажми **start-windows.cmd**. В первый раз скрипт скачает зависимости через npm; потребуется интернет. Приложение не требует прав администратора.
3. Откроются окно сервера и панель **http://127.0.0.1:3187**. Оставь окно сервера открытым на время стрима.
4. Нажми «Добавить 5 персонажей» или «Заполнить до 40» для проверки без Twitch. Тестовых участников можно убрать отдельно.
5. Чтобы остановить приложение, нажми **Ctrl+C** в окне сервера. Не запускай вторую копию: если порт занят, используй уже открытую панель.

Это первая версия с запуском через Node.js, **не установщик .exe**. Сервер, графика и зависимости работают локально; Twitch нужен только для подключения чата. Все клиентские ресурсы включены в сборку, CDN не используется. Скопированную с macOS папку `node_modules` на Windows переносить не нужно.

## Подключение OBS

1. В нужной сцене добавь **Источник → Браузер**.
2. URL: **http://127.0.0.1:3187/overlay**. «Локальный файл» выключен.
3. Ширина **1920**, высота **1080**. Если эфир другого разрешения, масштабируй источник в OBS. Сама сцена использует координаты 1920×1080.
4. Поставь источник выше игрового захвата. Не добавляй URL панели управления: она не предназначена для показа в эфире.
5. Оставь стандартный CSS OBS с прозрачным фоном. Включи аппаратное ускорение источника браузера, если графика не появляется.
6. Частоту кадров источника OBS выставь 30 (или 60, если выбрано 60 в панели). Обновление источника не сбрасывает участников: ими управляет сервер.

Шахматная сетка, кнопки и подписи предпросмотра находятся в панели. На оверлее их нет. Когда приложение отключено, браузерный источник не может получить новые данные: сначала запусти приложение, затем при необходимости обнови источник в OBS.

## Подключение Twitch

В этой версии используется **свой аккаунт стримера и его же канал**. Отдельный бот и Client Secret не нужны.

1. Открой https://dev.twitch.tv/console/apps и зарегистрируй приложение. Для регистрации Twitch может потребовать 2FA.
2. Укажи название, OAuth Redirect URL `http://localhost`, категорию **Application Integration**, тип клиента **Public**. Device Code Flow использует код устройства, а не Redirect URL.
3. Скопируй **Client ID**, вставь в панели и нажми «Подключить Twitch».
4. Перейди по кнопке на Twitch, введи выданный код и подтверди доступ аккаунтом своего канала.
5. После подключения напиши в чате `!join`. Эфир для проверки команд включать не обязательно.

Приложение запрашивает только `user:read:chat` — чтение чата. Оно не отправляет сообщения, не модерирует канал и не получает ключ стрима. Авторизация и обновление токена выполняются сервером; токены не отправляются в панель или оверлей. При обычном обрыве EventSub переподключается автоматически; при отзыве доступа панель предложит войти заново.

Если Twitch не выдаёт код, проверь тип клиента **Public**, Client ID и интернет. Список смотрящих видео не используется: зрители входят по команде либо первому сообщению, если включить настройку.

## Команды

| Команда | Действие |
|---|---|
| `!join` | Создать персонажа; после 40-го участника — встать в очередь |
| `!leave` | Убрать персонажа или выйти из очереди |
| `!jump` | Прыгнуть |
| `!dance` | Танцевать 3 секунды |
| `!skin 1` … `!skin 493` | Выбрать покемона по номеру Покедекса |
| `!skin pikachu` | Выбрать Пикачу; также работает `!skin 25` |
| `!skin charizard`, `!skin mew` | Выбрать по английскому ID из каталога |

Между действиями одного зрителя действует задержка **2,5 секунды**. Выход через `!leave` доступен сразу. Повторный `!join` не создаёт дубликат. В очереди до 200 мест; новые заявки сверх этого лимита не сохраняются. Сообщения из других каналов Shared Chat не добавляют участников.

Очередь заполняет освободившиеся места по порядку. По умолчанию персонаж уходит через 30 минут без сообщений; можно отключить таймер. Тестовые персонажи не удаляются по таймеру. Пауза останавливает анимации и прогулку; команды входа/выхода и таймер неактивности продолжают работать. «Убрать» в панели удаляет персонажа, но не блокирует повторный `!join`.

## Shiny-версии

По команде **`!skin число`** проводится один случайный розыгрыш shiny того же покемона, если такая версия доступна. По умолчанию шанс **1 из 128 (около 0,78 %)**. Например, `!skin 25` выдаёт обычного Пикачу или shiny-Пикачу.

В настройках сцены поле **«Шанс shiny: 1 из»** задаёт знаменатель: 64 → 1/64, 512 → 1/512. **0** отключает случайные shiny, **1** гарантирует shiny при наличии спрайта. Допустимы целые числа 0–8192. Настройка сохраняется; старые настройки автоматически получают значение 128.

Каждая принятая команда с номером — отдельная попытка, без накопления шанса. Существующая задержка 2,5 секунды действует и на попытки: команды во время задержки и неверные номера не запускают розыгрыш. Вход через `!join` сам по себе не даёт shiny; ранее сохранённый shiny восстанавливается.

`!skin pikachu` выбирает обычную версию без розыгрыша. Прямые shiny-ID вроде `!skin pikachu-shiny` в чате не принимаются: shiny выдаётся по шансу. В каталоге команда для любой версии использует номер. Стример может вручную выбрать обычную или shiny-версию, нажав на портрет участника и переключив фильтр каталога.

Shiny отличается окраской спрайта, золотой звёздочкой у ника в оверлее и отметкой в панели. Выбранная версия сохраняется за реальным зрителем. Если у покемона нет shiny-спрайта, остаётся обычная версия. В текущую подборку включены shiny для всех 493 видов.

## Сохранение и спрайты

Настройки и выбранные персонажи сохраняются в `.data/scene.json` рядом с приложением. Состав сцены и очередь после перезапуска очищаются. Обновление страницы и источника OBS сохраняет текущих участников, пока сервер работает.

Данные авторизации сохраняются локально в `.data/twitch.json` (обычный JSON, без шифрования Windows). Не передавай эту папку другим людям. «Отключить Twitch» удаляет локально сохранённые токены; полный отзыв разрешения доступен в настройках подключений Twitch. Релизный архив не включает `.data`.

Включены 493 анимированных покемона поколений I–IV и 493 shiny-версии из [PokéAPI/sprites](https://github.com/PokeAPI/sprites), от Bulbasaur до Arceus. Атласы и портреты включены в Windows-архив и загружаются локально. Исходные GIF преобразованы в PNG с сохранением последовательности и длительности кадров. Это боевые анимации; прогулка, прыжки и танцы добавляются движком сцены.

Кнопка **«Открыть каталог»** показывает всех покемонов, поиск по английскому имени или номеру и фильтры по поколению и версии. Выбери покемона, чтобы получить команду для чата. Для смены персонажа конкретного участника нажми на его портрет в списке: выбранный покемон сразу появится на сцене. Выбор реальных зрителей сохраняется между запусками; выбор тестовых участников не сохраняется.

Если в старом профиле был временный персонаж, при следующем `!join` вместо него выбирается случайный покемон. Остальные настройки сохраняются.

Собственные PNG/WebP и сетки анимации подключаются через **[SPRITES.md](SPRITES.md)**. В исходниках это `public/sprites`, в Windows-сборке — `dist/public/sprites`. После изменения манифеста перезапусти сервер и обнови источник OBS. Источник изображений, точные ревизии и лицензия указаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Для обновления уже установленной сцены: останови сервер, распакуй новый архив и перенеси свою папку `.data` в новую папку приложения. Она не включена в релиз и не должна заменяться чужими файлами. Запусти новый `start-windows.cmd` и обнови источник браузера OBS. URL и размер источника остаются прежними.

## Разработка и сборка

```sh
npm ci
npm run check
npm test
npm run build
npm start
```

`npm run package:windows` собирает `release/PokeParade-Windows.zip` без персональных данных и платформенных зависимостей. Сборка возможна на macOS; установка npm-зависимостей выполняется уже на Windows. Если запускаешь исходники на Windows, `start-windows.cmd` установит средства сборки и соберёт проект при первом запуске. После изменения исходников повторно выполни `npm run build`.

Браузерная проверка: `npx playwright install chromium`, затем `npm run test:browser`. Скрипт поднимает отдельный сервер с временными данными, проверяет каталог, поиск, выбор покемона, реальные кадры анимации, 40 спрайтов, движение, паузу, удаление и прозрачность оверлея. Снимки — `test-results/stage.png` и `test-results/pokemon-catalog.png`.

Повторный импорт изображений (только для разработки): установи зависимости из `scripts/requirements-assets.txt`, затем запусти `python scripts/import-pokemon.py --count 493`. Импортер использует ревизии из `scripts/pokemon-source.json`; исходники кэшируются в `.cache/pokemon`. Новые изображения активируются в манифесте только после успешной обработки всей подборки. Python и Pillow не нужны на игровом ПК. После импорта выполни `npm run package:windows`.

Стек: TypeScript, PixiJS 8, Node.js 22+, WebSocket, Twitch EventSub / Device Code Flow. Сервер слушает только `127.0.0.1`; внешний хостинг и открытие порта роутера не нужны. Открывай панель именно по `127.0.0.1`, а не `localhost` (проверяется адрес и источник запросов).

Переменные среды для разработки: `PORT` (по умолчанию 3187), `STAGE_DATA_DIR` (по умолчанию `.data`). Windows-скрипт закрепляет порт 3187.

## Основа для следующих активностей

- `src/server/scene.ts` — состав сцены, команды, очередь, состояния и движение. Здесь добавляются правила мини-игр.
- `src/server/twitch.ts` — авторизация и входящие события Twitch, отдельно от игровых правил.
- `src/client/overlay.ts` — только визуализация состояния и анимации.
- `src/shared.ts` — формат состояния сцены, настроек и персонажей.

Перед первым эфиром проверь нагрузку вместе с игрой и OBS на своём Windows-ПК. Здесь нет проверки реального аккаунта Twitch или запуска Windows OBS без доступа к этому ПК; локальные тесты используют демо и поддельные ответы Twitch.

Документация: https://obsproject.com/kb/browser-source · https://dev.twitch.tv/docs/chat/authenticating · https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow
